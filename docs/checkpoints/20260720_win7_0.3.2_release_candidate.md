## Status

- Date: 2026-07-20

- Release state: candidate only; no `v0.3.2` tag or GitHub release

## Implemented

- Win7 SP1-only double-click installer with current-user startup.
- Local-folder changes synchronize to the Ubuntu Samba share.
- Network failures retry quietly through a supervised, bounded worker.
- The first successful sync prompts before enabling Ubuntu-to-NAS uploads.
- Later changes submit unique encrypted upload jobs.
- Independent double-click uninstaller preserves Windows source, Ubuntu share,
  and NAS data.
- Primary DPAPI configuration has an atomic backup and recovery path.
- Ubuntu upload agent uses one startup owner and one running agent instance.

## Network Requirement

Current Tailscale for Windows releases do not support Windows 7. A Win7 client
must reach the Ubuntu UNC over a trusted LAN or through a supported Tailscale
subnet router/gateway. Do not bundle an unsupported legacy Tailscale client.

## Remaining Real Win7 Gate

Run on an actual Windows 7 SP1 machine:

1. Double-click install and configure the local folder, Samba, and NAS account.
2. Reboot and confirm exactly one tray process starts without a flashing
   console.
3. Disconnect and reconnect the network; confirm a later edit synchronizes.
4. Accept the first NAS prompt and verify the NAS file hash.
5. Change the temporary NAS password and verify another SSH-key upload.
6. Double-click uninstall and verify all three business-data copies remain.

Do not tag or publish `v0.3.2` before all six checks pass.
